# RebootGuard · 重启保护

一个轻量的 Windows x64 托盘工具，在后台任务运行期间**尽力阻止关机、重启和注销**。使用 Win32 API 与 C++17 编写，单个 EXE 约 153 KiB，可直接运行。

当前开发环境为 Windows 11 x64；Windows 10 尚未实机验证。

程序每隔约 1 秒尝试取消尚在倒计时内的关机，并在收到正常的会话结束询问时返回阻止结果。它不区分请求来源，因此也会影响你主动发起的普通关机、重启和注销。

## 下载与使用

从 [Releases 下载最新版本](https://github.com/gndb/RebootGuard/releases/latest)，解压后双击 `RebootGuard.exe`。启动后默认开启保护；单击或右键托盘图标可打开菜单。再次运行程序会打开已有实例的菜单。

| 托盘图标 | 状态 | 操作 |
| --- | --- | --- |
| 绿色暂停符号 | 已开启保护 | 后台尽力拦截 |
| 灰色播放符号 | 已解除保护 | 可以自行关机或重启 |
| 橙色感叹号 | 倒计时取消异常 | 打开菜单查看 Windows 错误码 |

![开启、解除、异常三种图标](assets/preview.png)

需要重启时，先选择 **“解除保护（不重启）”** 或 **“退出并解除保护”**，再通过 Windows 正常重启。这两个菜单项都不会主动重启电脑。橙色状态表示倒计时取消发生错误，不代表其他拦截环节也已关闭。

v1.0.0 发布 ZIP 包含 `RebootGuard.exe`、`install.ps1`、说明文档、图标预览及校验文件。可选运行安装脚本，将程序放入当前用户的 `%LOCALAPPDATA%\RebootGuard`，创建桌面和登录启动入口，并启动保护：

```powershell
.\install.ps1
```

安装脚本可使用发布包中同目录的 EXE，或源码构建生成的 EXE；已有安装不会被直接覆盖。便携运行无需安装。自动启动发生在用户登录后，不提供登录前的系统服务保护。

**手动升级已有安装：** 下载并解压新版本，在托盘选择“退出并解除保护”，备份安装目录中的旧 EXE，再用新 EXE 替换同名文件并运行。现有快捷方式可继续使用；退出到重新启动之间保护暂停。卸载时先退出程序，再删除安装目录及桌面、当前用户“启动”文件夹内的“重启保护”快捷方式。

## 适用范围

- **只锁屏，仍保持登录且电脑处于唤醒状态：** 程序可以继续运行，不依赖鼠标、键盘活动。
- **睡眠或休眠：** 程序不会持续执行；它不负责阻止睡眠。需要连续运行的任务应自行确认电源设置。
- **注销完成、退出程序或进程被结束：** 保护结束。
- **强制或关键关机、零或极短倒计时、系统崩溃、断电：** 无法保证拦截。约 1 秒的定时器也不是实时执行保证。

RebootGuard 不修改 Windows 更新策略、系统服务或电源设置，不主动发起关机或重启。若需要“手动更新”，应根据自己的 Windows 版本和管理环境单独配置；安装本程序不等于配置了更新策略。参见 [Microsoft 的 Windows Update 设置说明](https://learn.microsoft.com/en-us/windows/deployment/update/waas-wu-settings#configure-automatic-updates)。

## 从源码构建

需要 Windows、PowerShell、Visual Studio 或 Build Tools 的 **C++ 桌面开发工具**，以及 Windows SDK。脚本通过 `vswhere` 和已安装的 SDK 自动定位工具链，构建 x64 程序。

在仓库根目录运行：

```powershell
.\build.ps1                 # 运行单元测试并生成 build\RebootGuard.exe
.\build.ps1 -TestsOnly      # 仅构建、运行状态逻辑单元测试
.\build.ps1 -NativeTests    # 构建程序并运行单元测试、隔离的原生生命周期测试
.\package.ps1              # 将已构建的 EXE 打包至 dist/，版本取自 VERSION
```

原生测试用替身取消接口和独立实例，不发起系统关机或重启。它仅向自己的隐藏顶层窗口发送合成消息，并验证真实的关机阻止理由注册与托盘生命周期。测试通过不表示已验证真实强制重启拦截或锁屏过夜运行；详见 [实现与验证边界](docs/IMPLEMENTATION.md)。

## 仓库结构

| --- | --- |
| `src/` | Win32 程序、状态逻辑和图标资源定义 |
| `tests/` | 状态单元测试、隔离原生测试 |
| `assets/` | 内嵌图标 |

| `docs/` | 实现说明 |

| `VERSION` | 发布版本号 |
